# 生成艺术 SVG 海报设计器

参数化生成艺术工具，支持螺旋、分形树、波浪、圆环、噪声场五种图案，8 种颜色主题，SVG/PNG 导出。

## 功能

- 5 种图案类型：螺旋、分形树、波浪、圆环、噪声场
- 8 种预设颜色主题（日落、海洋、霓虹、森林、单色、糖果、火焰、极光）
- 种子随机数生成器（确定性重现）
- 参数实时预览：迭代数、缩放、旋转、描边、透明度
- SVG 矢量导出 & PNG 高清导出
- **分段生成**：每种图案按绘制过程分段产出（每段带序号与所属图案），支持按段回放、单段复用与多次生成对比
- **构建期校验**：`vite build` 按固定参数跑一遍五种图案的分段产出，校验段序无缺失/重复、各段拼回结果与一次性生成逐字符一致，不通过则构建失败并指出是哪种图案的第几段
- **分段结果本地复用**：校验通过的分段结果固化在 `frontend/src/generated/segments/*.json`（含参数指纹 key），运行时优先复用构建产物，其次复用 localStorage 缓存，未命中才实时生成

## 分段机制

- `src/generators/patterns.ts`：一次性生成器（对照基准，保持原实现不变）
- `src/generators/segments.ts`：分段生成器注册表，段定义为——螺旋每条旋臂一段、分形树每条树枝一段、波浪每层一段、圆环每个圆一段、噪声场每一扫描行一段
- `src/generators/segmentStore.ts`：分段结果的本地保存与复用（构建产物 → localStorage → 实时生成）
- `scripts/segment-build-plugin.mjs`：Vite 构建插件，负责固定参数分段产出、段序/拼合校验与产物落盘
- 画布下方提供「按段回放 / 上一段 / 下一段 / 完整画面」控件；参数或图案缺失（如未实现的 voronoi）会在日志与构建输出中说明原因，不会静默跳过

## 技术栈

- React + TypeScript + Vite
- D3.js（数据处理）
- Zustand（状态管理）
- Tailwind CSS

## 运行

```bash
cd frontend && npm install && npm run dev
```
